# Генератор паролей

Консольная утилита, которая генерирует надёжные пароли. Один файл, никаких
зависимостей — скачал, собрал, пользуешься.

## Чем хорош

**Настоящая случайность.** Использует системный источник энтропии
(`std::random_device`), а не `mt19937`. Разница
принципиальная: состояние вихря Мерсенна восстанавливается по его же выводу,
то есть по одному паролю можно вычислить все остальные.

**Пароль пройдёт любую форму регистрации.** Гарантирует хотя бы один символ
из каждого выбранного набора, так что не придётся генерировать заново из-за
«пароль должен содержать цифру».

**Показывает надёжность в битах энтропии.** Сразу видно, 40 бит вы получили
или 100.

**Работает везде.** Linux, Windows, macOS. Нужен только компилятор C++17.

## Запуск

**Linux и macOS**

```
g++ -std=c++17 -O2 password_generator.cpp -o passgen
./passgen
```

На macOS `g++` — это clang, команда та же.

**Windows**

Найдите в «Пуске» Developer Command Prompt for VS и выполните:

```
cl /std:c++17 /O2 /EHsc /utf-8 password_generator.cpp
password_generator.exe
```

Флаг `/utf-8` обязателен, иначе вместо русского текста будут кракозябры.

С MinGW — как на Linux, только `-o passgen.exe`.

## Как пользоваться

Программа задаёт шесть вопросов: длину, количество и какие наборы символов
использовать. В скобках показано значение по умолчанию — жмите Enter, чтобы
его принять. Шесть раз Enter = пять паролей по 16 символов.

```
Длина пароля [16]:
Сколько паролей сгенерировать [5]: 3

Надёжность: до ~102 бит энтропии на пароль

Ваши пароли:
  1) 7bQ$vKm2*xRa9Tf!
  2) Hs3#NpZq8@cVy1Bu
  3) 4Xe%Rm7Jt-Wn6Fg^
```
